# Long-term Memory

`memory/MEMORY.md` is the one document the agent writes directly; Dream curates it
afterwards, promoting entries into `SOUL.md`, `USER.md`, skills or custom documents.

One fact per bullet, digested in your own words, with a provenance note
`(source)`:

```markdown
- Nightly deploy runs at 02:00 local time (owner said)
- Release feed needs two reviewers (https://example.com/releases)
```

Never write a date into an entry — the system derives an entry's age from its own
snapshot history, and a date you invent becomes a false fact the model restates.

Never paste raw external content (page text, payloads, snapshots) here — keep the
digest and cite the source or its reference path.
